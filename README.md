# Taller 6 - GUIs con Swing y Java2D

Aplicación para llevar un diario de restaurantes visitados y por visitar.

## Cómo ejecutar

1. Abrir el proyecto en Eclipse (File > Import > Existing Projects into Workspace).
2. Abrir el archivo `src/uniandes/dpoo/swing/interfaz/principal/VentanaPrincipal.java`.
3. Clic derecho dentro del archivo > **Run As > Java Application**.

Se abre la ventana principal. Desde ahí se puede:

- **Nuevo**: abre la ventana para agregar un restaurante (clic en el mapa para marcar su ubicación).
- **Ver todos**: abre el mapa con los restaurantes (se pueden filtrar por "Todos" o "Visitados").

> Importante: no mover ni renombrar la carpeta `imagenes`, porque la aplicación carga las imágenes desde ahí.
